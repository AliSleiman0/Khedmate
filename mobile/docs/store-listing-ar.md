## الوصف الكامل (حد أقصى 4000 حرف — Play Store)

**تطبيق واحد. اختر دورك. أنجز يومك.**

خدمتي يربط البيوت في المملكة العربية السعودية بمحترفين معتمدين للخدمات المنزلية. سواء كنت تحتاج عامل نظافة اليوم، سباك بعد الظهر، أو فني تكييف قبل نهاية الأسبوع — خدمتي يحجز لك الخدمة خلال دقائق، ويدفع للفني بأمان بعد إنجاز العمل.

**للعميل**
- احجز في أقل من دقيقة — اختر الفئة، اوصف الخدمة، حدد الموقع على الخريطة، وأكّد.
- شفافية كاملة في السعر قبل الحجز — بدون رسوم مفاجئة.
- تابع مزود الخدمة على الخريطة مباشرة وهو في طريقه إليك.
- ادفع بأمان عبر التطبيق — المبلغ محجوز حتى تعتمد إنجاز العمل.
- دردشة داخل التطبيق مع الفني، قبل وخلال الخدمة.
- قيّم الخدمة لتحسن تجربة العميل القادم.
- اكسب رصيداً عند دعوة أصدقائك — 20 ريال لكل عميل جديد، و15% خصم لأول حجز للصديق.

**للفني**
- تصلك الطلبات القريبة منك في الوقت الفعلي عبر الإشعارات.
- لديك دقيقتان لقبول أو رفض كل طلب.
- تفاصيل كاملة عن الطلب وملاحة مباشرة لموقع العميل.
- ارفع صور قبل وبعد الخدمة لتوثيق عملك.
- صفحة أرباح شفافة — العمولات، التحويلات، والإحصائيات في مكان واحد.
- تحويلات أسبوعية عبر Stripe إلى حسابك البنكي.
- اشتراك Power Provider الاختياري: عمولة أقل وأسبقية 30 ثانية على كل طلب جديد.

**موثّق، خاص، آمن**
- كل فني معتمد هوياً ومُختبر مهارياً قبل قبول الطلبات.
- جميع المدفوعات تتم بأمان عبر Stripe.
- كل التواصل داخل التطبيق — رقم هاتفك لا يُشارك أبداً.

**اللغات:** العربية (الرئيسية) والإنجليزية.
**المدن:** الرياض حالياً، ونتوسع في المملكة.

## أمان البيانات / بطاقة خصوصية Apple

البيانات المجمعة والغرض منها:

| نوع البيانات | يتم جمعه | يُشارك | الغرض |
|---|---|---|---|
| الاسم | ✓ | لا | وظائف التطبيق (الحساب) |
| البريد الإلكتروني | ✓ (للعملاء فقط) | لا | وظائف التطبيق، استرجاع الحساب |
| رقم الهاتف | ✓ | لا | التحقق والتواصل |
| الموقع الدقيق | ✓ | الفنيون يشاركونه مع العميل المُكلّف فقط خلال حالة "في الطريق" | الملاحة، المطابقة، التتبع المباشر |
| الموقع التقريبي | ✓ | لا | إيجاد الفنيين القريبين |
| الصور | ✓ | لا | توثيق الخدمة (قبل/بعد) |
| معلومات الدفع | ✓ | Stripe (معالج متوافق مع PCI) | معالجة المدفوعات |
| تفاعلات التطبيق | ✓ | Firebase (التحليلات) | الأداء ومنع الاحتيال |
| سجلات الأعطال | ✓ | Firebase Crashlytics | مراقبة الاستقرار |
| معرّفات الجهاز | ✓ (رمز FCM) | لا | الإشعارات |

**حذف البيانات:** يمكن للمستخدم حذف حسابه من داخل التطبيق عبر: الملف الشخصي ← حذف الحساب. تُحذف البيانات خلال 30 يوماً؛ تُحفظ السجلات المالية وفق قانون الضريبة.

## الأذونات والمبرر

| الإذن | المبرر داخل التطبيق |
|---|---|
| `ACCESS_FINE_LOCATION` | العميل: تحديد عنوان الخدمة بدبوس على الخريطة (اختياري). الفني: الملاحة لموقع العميل. |
| `ACCESS_BACKGROUND_LOCATION` | **للفنيين فقط.** يرسل موقع الفني للعميل كل 3 ثوانٍ أثناء حالة "في الطريق" فقط ليرى العميل الفني على خريطة مباشرة. يتوقف فور الضغط على "وصلت". |
| `CAMERA` | الفني: تصوير قبل/بعد الخدمة. العميل: تصوير المستند أثناء رفع النزاع (اختياري). |
| `POST_NOTIFICATIONS` | إشعارات حالة الطلب، رسائل الدردشة، تذكيرات الصيانة. |
| الميكروفون | رسائل صوتية في الدردشة (ميزة مستقبلية — الإذن معلن ولكنه غير مستخدم حالياً). |

## التوافق مع تعليمات Apple 5.1.2

**حذف الحساب من داخل التطبيق:** الملف الشخصي ← "حذف الحساب" ← رسالة تأكيد ← حذف نهائي من الخادم، مسح الرموز محلياً، والعودة لشاشة الترحيب.

**تسجيل الخروج:** الملف الشخصي ← "تسجيل الخروج" ← مسح الرموز، والعودة لشاشة الترحيب.

**الاحتفاظ بالبيانات بعد الحذف:** جميع البيانات الشخصية تُحذف خلال 30 يوماً. السجلات المالية (المعاملات، التحويلات) تُحفظ 7 سنوات وفق قانون الضريبة السعودي — موضّح في سياسة الخصوصية `https://khudmati.app/privacy`.

## التوافق مع تعليمات Apple 3.1.1

اشتراك Power Provider الشهري (99 ريال) هو **ترقية طبقة عمولة للفنيين**، وليس سلعة رقمية. الدفع عبر Stripe وليس StoreKit — نفس نموذج اشتراكات Uber للسائقين، DoorDash Premium، إلخ. راجع 3.1.3(e) — استثناء "الخدمات".
