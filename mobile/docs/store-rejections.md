# Store Rejection Log

Track every rejection from Play Store or App Store here. Empty is the goal.

## Format

```
### <YYYY-MM-DD> — <Apple|Google> — <guideline cited>

**Submission:** v<version> build <build> (unified app)
**Reviewer note:** <verbatim quote from the email / console>
**Root cause:** <1–2 lines — why the submission actually failed>
**Fix:** <what we changed + PR / commit>
**Resubmitted:** <YYYY-MM-DD> → <approved | rejected again>
```

Keep older entries at the bottom. Newest on top.
